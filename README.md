# FAMPER Game Fest

O **FAMPER Game Fest** é um campeonato fictício de jogos eletrônicos, reunindo jogadores de diversas modalidades em um evento cheio de competições, ranking, premiações e muita diversão.

## Funcionalidades
- Página inicial com destaque para a edição 2026
- Informações sobre o evento e estatísticas
- Lista de alguns jogos disponíveis:
  - Minecraft
  - Fortnite
  - Valorant
  
- Regras do campeonato
- Programação das partidas
- Ranking dos participantes
- Premiações
- Formulário de inscrição
- Contato e redes sociais

## Tecnologias utilizadas
- **HTML**
- **CSS**

## Como usar
1. Clone este repositório.
2. Abra o arquivo `index.html` em seu navegador.
3. Explore as seções
